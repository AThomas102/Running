**Block rotation (once mileage is sustainable) — agents must watch these:**

1. **Base / mileage** (4–6 weeks): volume focus, strides, little hard work → deload  
2. **Threshold** (3–5 weeks): tempo/LT quality + steady long → deload  
3. **VO₂ / race-specific** (3–5 weeks): track/AC + race-pace → **peak/taper** for A-race  
4. **Recovery / transition** (1–2 weeks): easy only, then restart  

End a block early if foot, sleep, or easy-pace markers deteriorate. Peak for chosen A-races only (e.g. one spring 5k/10k, one autumn HM) — not every parkrun.
