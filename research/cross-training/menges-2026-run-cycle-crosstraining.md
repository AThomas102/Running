# Menges et al. 2026 — Running ↔ cycling cross-training

## Key findings

- Systematic review/meta-analysis comparing running-only vs cycling-only interventions for transfer to VO2max and running performance.
- Pooled effects: **no statistically significant differences** between run-only and cycle-only for treadmill VO2max, cycle VO2max, or running performance outcomes; CIs included the null; effects small and uncertain in direction.
- Practical interpretation in the broader cross-training literature: **central aerobic capacity** can be trained on the bike, but **running economy, impact tolerance, and gait-specific adaptations** do not fully transfer from cycling.

## Limitations

- Limited/heterogeneous trials; uncertainty remains high.
- Does not specifically study “easy commute doubles + separate run plan” as used by this athlete.

## Planning implications

- **Recommend easy bike** (including extending commute spins) to add aerobic stimulus **without foot impact** during rebuild and on rest-from-running days.
- Do **not** replace key run sessions (long run, strides/quality) with cycling if the goal is run race performance.
- Count bike as useful support load; still progress **run-specific** volume carefully for HM/5k goals.
