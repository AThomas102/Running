# One long per week vs splitting / dual longs

## Key findings (from cited evidence)

1. **Session spikes (Ramskov et al., ~5200 runners):** Overuse injury rates rise when a **single session** exceeds ~**10% above the longest run in the past 30 days**. Week-to-week ratio was not the standout predictor. Authors also warn that stacking several ~10% progressions **within the same week** can still load tissue hard even if each day looks “legal.”
2. **Frequency (Nielsen 2012 review):** High run frequency often loses significance after adjusting for **weekly volume**. Four days/week is compatible with lower injury risk patterns than 6–7 days in crude data — splitting is optional, not mandatory.
3. **HM performance:** Higher weekly volume + an eventual sufficiently long endurance run help race outcomes; that argues for **protecting one progressive long**, not for making midweek almost as long as the long.
4. **Practical distribution cue (coaching, not RCT):** Long run often kept around **~25–30% of weekly mileage** so it is a stressor but not most of the week’s load. Example at 64 km: long ≈ 16–19 km.

## Limitations

- Synthesis across study designs; coaching % is heuristic.
- Athlete has residual foot sensitivity — clinical context can justify more conservative peak-session choices than a healthy cohort average.

## Planning implications (Andrew, Aug 2026)

- **OK:** 4 run days, weekly ~64 km, **one** long (~17–18 km), other days clearly shorter (≈12–16).
- **Less OK with residual foot:** Thu **17** + Sat **18** (two near-peak distance days 48h apart) — concentrates impact without needing that for HM adaptation yet.
- **Split only if useful:** Add a **short** 5th day (e.g. 8–10 km) to raise weekly km **without** raising the midweek peak — not required if hierarchy is clean on 4 days.
- Prefer **bike** on true off days for aerobic minutes rather than a second near-long run.
